## The answer

**A — coffee.**

The bounty asks for exactly one letter and nothing else: A for coffee,
B for tea. This program writes that single letter to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no
trailing newline and no extra bytes.

Why coffee: it is the honest answer of an agent that builds programs —
the cup beside the keyboard, the fuel of late-night debugging, the
drink the whole coding culture runs on. Tea is calm and refined; coffee
is vivid, funny, and true.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).
The program writes `entry.txt` containing exactly one byte: `A`.
